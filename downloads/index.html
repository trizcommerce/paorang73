뽕커벨님 콘텐츠 캘린더

콘텐츠 일정을 휴대폰 앱으로 바로 봐요

안드로이드 휴대폰

APK 설치하기
  1. 내려받은 paorang73-calendar.apk 파일을 눌러요.
  2. ‘출처를 알 수 없는 앱’ 안내가 나오면 설정 → 이 출처 허용을 켜고 돌아와요.
  3. 설치를 눌러요. Play 프로텍트 안내가 나오면 무시하고 설치를 눌러요.

새 버전이 나오면 앱을 열 때 업데이트 안내가 떠요. 지우지 않고 그대로 덮어써요.

웹 브라우저 바로가기로 설치하기
  1. 크롬에서 이 페이지를 열고 위 버튼을 눌러요.
  2. ‘설치’를 누르면 홈 화면에 ‘뽕커벨 캘린더’ 아이콘이 생겨요.
  3. 버튼이 안 눌리면 크롬 오른쪽 위 ⋮ → 앱 설치(또는 ‘홈 화면에 추가’)를 눌러요.

아이폰

설치 프로필 내려받기
  1. Safari에서 이 페이지를 열고 위 버튼을 눌러요. ‘허용’을 눌러요.
  2. 설정 앱을 열면 맨 위에 프로파일이 다운로드됨이 보여요. (안 보이면 설정 → 일반 → VPN 및 기기 관리)
  3. 설치를 누르고 휴대폰 암호를 입력하면 홈 화면에 ‘뽕커벨 캘린더’ 아이콘이 생겨요.
  4. 파일이 ‘파일’ 앱에 저장되기만 하면, 파일 앱 → 다운로드에서 paorang73-calendar.mobileconfig를 눌러 주세요. 그다음은 2번과 같아요.
웹 브라우저 바로가기로 설치하기 캘린더 열기
  1. Safari에서 위 버튼으로 캘린더를 열어요.
  2. 아래쪽 공유 버튼(네모에 위 화살표)을 눌러요.
  3. 홈 화면에 추가 → 추가를 누르면 홈 화면에 ‘뽕커벨 캘린더’ 아이콘이 생겨요.

내용은 인터넷에서 바로 불러와서, 시트가 바뀌면 앱을 다시 설치하지 않아도 최신 내용이 보여요.
