캘린더를 휴대폰 앱처럼 쓰려면 설치 방법을 골라 주세요.

카카오톡 안에서 열렸어요

여기서는 설치가 안 돼요. 크롬으로 다시 열어 주세요.

앱으로 설치하기
자세한 설치 방법 보기

안드로이드 · 크롬

먼저 이 캘린더 링크를 크롬으로 열어요. (카카오톡에서 받았다면 오른쪽 위 ⋮ → 다른 브라우저로 열기)

바탕화면 바로가기 (추천)
  1. 창에서 바탕화면 바로가기를 누르면 ‘앱 설치’ 창이 떠요. 설치를 누르면 끝이에요.
  2. 창이 안 뜨면 크롬 오른쪽 위 ⋮ → 앱 설치(또는 홈 화면에 추가 → 설치)를 눌러요.
앱(APK)으로 설치
  1. 창에서 앱으로 설치하기를 펼치고 앱(APK)으로 설치를 눌러요. 앱 파일을 내려받기 시작해요.
  2. 다 받으면 화면 위 알림(또는 크롬 아래 ‘열기’)에서 파일을 눌러요.
  3. ‘출처를 알 수 없는 앱’이 나오면 설정 → 이 출처 허용을 켜고 뒤로 돌아와요.
  4. 설치를 눌러요. Play 프로텍트 안내가 나오면 무시하고 설치(또는 ‘세부정보 더보기 → 무시하고 설치’)를 눌러요.
  5. 홈 화면에 생긴 캘린더 아이콘을 눌러 열어요.
삼성 인터넷을 쓴다면
  1. 아래쪽 ≡ 메뉴 → 현재 페이지 추가 → 홈 화면을 눌러요.

아이폰 · 사파리

먼저 이 캘린더 링크를 사파리로 열어요. (카카오톡에서 받았다면 오른쪽 아래 공유(↑) → Safari로 열기, 인스타그램은 오른쪽 위 ⋯ → 외부 브라우저에서 열기)

홈 화면 바로가기 (추천)
  1. 사파리 아래쪽 공유 버튼(네모에 위 화살표)을 눌러요. 주소창이 위에 있으면 주소창 옆 ⋯을 먼저 눌러요.
  2. 목록을 내려 홈 화면에 추가를 눌러요.
  3. 오른쪽 위 추가를 누르면 끝이에요.
앱으로 설치 (설치 프로필)
  1. 창에서 앱으로 설치하기를 펼치고 앱으로 설치 (설치 프로필)을 눌러요.
  2. ‘구성 프로파일을 다운로드하시겠습니까?’에서 허용을 눌러요.
  3. 설정 앱을 열면 맨 위에 프로파일이 다운로드됨이 보여요. 눌러요. (안 보이면 설정 → 일반 → VPN 및 기기 관리)
  4. 오른쪽 위 설치 → 휴대폰 암호 입력 → 설치를 한 번 더 눌러요. ‘확인되지 않음’ 표시는 그대로 진행해도 돼요.
  5. 홈 화면에 생긴 캘린더 아이콘을 눌러 열어요.
아이폰에서 크롬을 쓴다면
  1. 주소창 오른쪽 공유 버튼 → 홈 화면에 추가를 눌러요. (안 보이면 사파리로 열어 주세요)

컴퓨터 · 크롬 / 엣지

바탕화면 바로가기 (추천)
  1. 창에서 바탕화면 바로가기를 누르고 설치를 눌러요.
  2. 창이 안 뜨면 주소창 오른쪽의 설치 아이콘(모니터에 화살표)을 눌러요.
  3. 그래도 없으면 크롬 오른쪽 위 ⋮ → 전송, 저장, 공유 → 페이지를 앱으로 설치(또는 바로가기 만들기 → ‘창으로 열기’ 체크)를 눌러요. 엣지는 … → 앱 → 이 사이트를 앱으로 설치예요.
  4. 바탕화면과 시작 메뉴에 캘린더 아이콘이 생겨요.
